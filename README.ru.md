# Kubek Companion

**Серверный плагин, который даёт панели [Kubek](https://github.com/Seeroy/kubek-minecraft-dashboard) взгляд изнутри сервера**

TPS, MSPT, heap и GC, миры, игроки, события и отчёт о лагах, а ещё объявления, тайтлы, отсчёт до рестарта и режим техработ. Всё управляется из панели

## ✨ Возможности

### Метрики

- TPS за 1, 5 и 15 минут из самого дешёвого источника, какой есть у сервера
- MSPT: на Paper avg, p50, p95, p99 и max, на Spigot оценка, на Folia по регионам
- Heap, non-heap, потоки и GC, включая реальные stop-the-world паузы
- Миры с количеством чанков, сущностей и тайлов
- Игроки: мир, режим игры, пинг, время сессии и, если нужно, координаты

### События

- Вход, выход, кик, смерть и достижения
- Чат, только пока в панели включено логирование чата
- Собираются в пачку раз в секунду, так что активный чат не заваливает панель

### Действия из панели

- Объявление и тайтл с цветами через `&`
- Отсчёт до рестарта с сообщениями в чат и боссбаром. Плагин только считает, рестарт делает панель
- Режим техработ: вход отклоняется ещё до того, как игрок появится в мире, опы и белый список проходят
- Отчёт о лагах по запросу: топ типов сущностей, самые тяжёлые чанки и задачи планировщика по плагинам
- Список плагинов с версиями, авторами и зависимостями

### Игроки его не замечают

- Ни команд, ни прав, ни конфига, ни папки с данными
- Ничего не пишет в чат, пока панель не попросит
- Без панели не делает вообще ничего: ни слушателей, ни задач, ни вывода

## 🧩 Поддерживаемые серверы

Один jar на всё: Spigot, Paper и Purpur от 1.8.8 до 26.3, а также Folia. Собирается под API 1.8.8 с байткодом Java 8, всё новее ищется на лету

| Что                                    | Paper                                            | Spigot / старый Paper                | Folia                          |
| -------------------------------------- | ------------------------------------------------ | ------------------------------------ | ------------------------------ |
| TPS за 1/5/15 мин                      | `Server.getTPS()`                                | поле `recentTps`                     | худший регион, `getRegionTPS`  |
| MSPT                                   | точно, по событиям тика (avg, p50, p95, p99, max) | оценка по состоянию главного потока  | среднее региона за 5 с         |
| Пинг                                   | да                                               | 1.17+                                | да                             |
| Счётчики тайлов, тайлы в отчёте о лагах | 1.11.2+                                          | нет                                  | только счётчики                |
| Боссбар для отсчёта                    | 1.9+                                             | 1.9+                                 | 1.20+                          |

Проверено на Paper 1.8.8, 1.12.2, 1.20.4 и 26.3, а также на Folia 26.3. С подключённым игроком проверяли на 1.8.8 и 1.12.2. Чистый Spigot и Purpur пока не запускались

## 🪶 Нагрузка на сервер

- Раз в интервал (по умолчанию 15 с) плагин копирует с главного потока несколько счётчиков. JSON, подпись и вывод делает один фоновый поток с низким приоритетом
- На Paper MSPT берётся из `ServerTickEndEvent`, обработчик сохраняет одно число за тик
- На Spigot фоновый поток примерно 100 раз в секунду смотрит на состояние главного потока, сам главный поток не трогается
- Отчёт о лагах и список плагинов строятся, только когда их просит панель, отчёт о лагах не чаще раза в 10 с
- Слушатель чата регистрируется, только пока включено логирование чата

## 🔌 Как плагин общается с панелью

Через stdout и stdin самого сервера, без портов и файлов.

- Фреймы пишутся прямо в дескриптор stdout в обход логгера, поэтому в `latest.log` они не попадают. Это OSC escape-последовательности, терминалы их прячут
- Запросы панель вводит в консоль подписанными строками. Плагин перехватывает и отменяет их до того, как сервер начнёт искать команду
- Включается плагин переменной `KUBEK_COMPANION_TOKEN`, её задаёт панель при запуске сервера. Все сообщения в обе стороны подписаны HMAC-SHA256 с этим токеном, старые и повторные запросы отбрасываются

## 📦 Установка

1. Положите `KubekCompanion-<версия>.jar` в папку `plugins/` сервера
2. Запустите сервер из Kubek

Всё. Если сервер запущен не из Kubek, плагин просто лежит и ничего не делает

---

## 🛠️ Сборка из исходников

Нужны JDK 17 (более новые JDK уже не умеют собирать под Java 8) и Maven

```bash
git clone https://github.com/KubekPanel/kubek-companion.git
cd kubek-companion
mvn package
```

Jar окажется в `target/KubekCompanion-<версия>.jar`
